<h2 align="center">╭・ ABOUT ME ・╮</h2>

Hi! I'm **Esma Bouhouche**, a fifth-year Computer Science Engineering student specializing in **Ingénierie des Systèmes Informatiques (ISI)** at the Higher School of Computer Science — Sidi Bel Abbès (ESI-SBA), Algeria.

I'm interested in building intelligent systems that connect software, hardware, and data — from microcontrollers and sensors to backend services and real-time monitoring dashboards.

- 🔌 **IoT & Embedded Systems:** Sensor integration, microcontrollers, hardware-software communication, and MQTT-based applications.
- 🤖 **Artificial Intelligence:** Exploring machine learning, data processing, and intelligent IoT solutions.
- 💻 **Software Engineering:** Web development, backend fundamentals, databases, and system design.
- 🌱 **Currently Learning:** Strengthening my Python, IoT architectures, AI/ML, and software development skills through hands-on projects.
- 🎯 **Career Goal:** Seeking internship opportunities in IoT, embedded systems, AI, or software engineering.
